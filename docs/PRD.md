## 1. الرؤية والهدف

### الرؤية
منصة رقمية سعودية متكاملة تُمكّن المسافر العربي من اكتشاف البرامج السياحية والدراسية بالخارج — من التصفح والاختيار حتى المتابعة اليومية — في مكانٍ واحد وبشفافية تامة.

### الهدف
بناء منظومة تجمع بين **العملاء** الباحثين عن تجارب سفر منظّمة، و**الوكلاء** الراغبين في تسويق برامجهم، و**إدارة المنصة** التي تُشرف على العمليات وتضمن الجودة — مع نظام مالي واضح لتوزيع العمولات وتتبّع المدفوعات.

### الوضع الحالي
المنتج في مرحلة **MVP مكتمل** ومنشور بالكامل، يشمل جميع الميزات الموثّقة في هذه الوثيقة.

## 2. المشكلة والفرصة

### المشكلة
| الجهة | المشكلة |
|-------|---------|
| **العميل** | لا توجد منصة عربية موثوقة تعرض جداول الرحلات اليومية بشفافية كاملة قبل الحجز |
| **الوكيل** | أدوات إدارة البرامج والمتابعة المالية مبعثرة أو غير موجودة بالعربية |
| **مزوّد الخدمة** | صعوبة بناء قاعدة عملاء وتتبّع العمولات بدون نظام احترافي |

### الفرصة
- سوق السياحة الداخلية السعودية في نمو متسارع (رؤية 2030)
- الطلب المتزايد على برامج الدراسة بالخارج من الشباب السعودي
- غياب منصة عربية أولى (RTL-native) تجمع السياحة والدراسة معاً
- نموذج عمل قابل للتوسع عبر شبكة الوكلاء

## 3. المستخدمون المستهدفون

### 3.1 العميل العادي (Public User)

| الخاصية | التفاصيل |
|---------|---------|
| **من هو** | مسافر سعودي أو عربي يخطّط لرحلة سياحية أو دراسة بالخارج |
| **هدفه** | إيجاد برنامج مناسب، معرفة التفاصيل والسعر، والحجز بسهولة |
| **احتياجاته** | جدول يومي واضح، سعر شفاف، متابعة مستمرة بعد الحجز |
| **نقطة ألمه** | عدم الوضوح في التفاصيل، غياب المتابعة بعد الدفع |

**رحلة العميل:**
```
تصفّح البرامج → اختيار البرنامج → الاطلاع على الجدول اليومي
     → طلب الحجز → تلقّي رمز المتابعة → متابعة رحلته عبر /b/[code]
```

---

### 3.2 الوكيل / الشريك (Agent)

| الخاصية | التفاصيل |
|---------|---------|
| **من هو** | شركة سياحة أو فرد يقدّم خدمات السفر والدراسة |
| **هدفه** | بناء وتسويق برامجه، إدارة عملائه، وتتبّع عمولاته |
| **احتياجاته** | أدوات إنشاء البرامج، رابط إحالة خاص، كشف حساب واضح |
| **نقطة ألمه** | غياب نظام موحّد لإدارة البرامج والمالية معاً |

**دورة حياة الوكيل:**
```
التقديم عبر النموذج → مراجعة الإدارة → الموافقة → إنشاء البرامج
     → مشاركة رابط الإحالة → إدارة الحجوزات → استلام العمولات
```

---

### 3.3 المشرف (Admin)

| الخاصية | التفاصيل |
|---------|---------|
| **من هو** | فريق تشغيل منصة خطار |
| **هدفه** | الإشراف على كامل العمليات وضمان جودة المنتج |
| **احتياجاته** | لوحة تحكم شاملة، أدوات إدارة كاملة، تقارير مالية |
| **مسؤولياته** | الموافقة على الوكلاء والبرامج، تأكيد الحجوزات، إدارة المدفوعات |

## 4. ميزات المنتج الحالية

### 4.1 الواجهة العامة (Public)

#### الصفحة الرئيسية `/`
- Hero section قابل للتخصيص (عنوان وعنوان فرعي من لوحة التحكم)
- بحث سريع بالنوع (سياحة / دراسة) والوجهة
- إحصائيات المنصة (الوجهات، البرامج، المدن، الدعم)
- بطاقات الفئات الأربع: رحلات داخلية، رحلات خارجية، دراسة لغة، جامعات وابتعاث
- البرامج المميزة (سياحة + دراسة)
- الوجهات المختارة بشبكة عرض mosaic
- شريط "رحلتك الدراسية" مع CTA
- قسم "كيف يعمل خطار؟" (3 خطوات)
- آراء العملاء (شهادات يديرها المشرف)
- قسم الانضمام كوكيل

#### البرامج السياحية `/programs`
- تصفّح كامل البرامج المنشورة والمعتمدة
- فلترة بـ chip filter: كل الأنواع / داخلي / دولي
- فلترة إضافية بالوجهة (قائمة منسدلة)
- عداد النتائج + زر مسح الفلاتر
- بطاقة البرنامج: صورة، اسم، ملخص، سعر ابتداءً من، المدة، الوجهة

#### تفاصيل البرنامج السياحي `/programs/[slug]`
- صورة غلاف بارزة مع breadcrumb
- نظرة عامة: ملخص، وصف، السعر/الشخص
- الجدول اليومي التفصيلي: أنشطة، تنقلات، فنادق، وجبات، رحلات جوية بأوقاتها
- قائمة "يشمل" و"لا يشمل"
- نموذج طلب الحجز (الاسم، الهاتف، البريد، التاريخ، عدد البالغين والأطفال)
- زر تواصل عبر واتساب
- Sticky inner nav للتنقل بين أقسام الصفحة

#### برامج الدراسة `/study`
- تصفّح برامج الدراسة بالخارج
- chip filters: كل الأنواع / دراسة لغة / جامعي / ابتعاث
- نفس تجربة التصفّح والفلترة
- Hero banner مع أيقونة وgradient مميز

#### تفاصيل برنامج الدراسة `/study/[slug]`
- اسم المعهد، المدينة الدراسية، مدة الدراسة
- نطاق الرسوم الدراسية (من / إلى)
- قائمة المتطلبات وقائمة الخدمات المشمولة
- نموذج حجز مخصّص للدراسة

#### الوجهات `/destinations`
- بطاقات الوجهات بتصميم overlay غامر
- النوع (داخلية / دولية)
- عدد البرامج المتاحة لكل وجهة

#### تفاصيل الوجهة `/destinations/[slug]`
- Hero بارتفاع 60% من الشاشة مع صورة كاملة
- وصف الوجهة
- المدن والمناطق (REGION → PROVINCE → CITY → DISTRICT)
- أبرز المعالم والأنشطة مع تصنيف لوني حسب الفئة والتكلفة التقديرية
- البرامج المتاحة في هذه الوجهة

#### متابعة الحجز `/b/[code]`
- صفحة عامة لا تتطلب تسجيل دخول
- التحيّة بالاسم الأول للعميل
- حالة الحجز مع badge مرئي
- تفاصيل الرحلة (التاريخ، عدد المسافرين)
- الجدول اليومي من البرنامج المرتبط
- مؤشر التقدّم (Milestones) خاصة لبرامج الدراسة
- الدفعات: الإجمالي، المدفوع، المتبقي (يظهر بعد QUOTED)
- التحويلات المجدولة مع بيانات السائق
- المحادثة مع فريق الدعم
- بيانات التواصل (وكيل أو إدارة المنصة)

#### صفحات أخرى
- تواصل معنا `/contact` — نموذج تواصل + بيانات المنصة + واتساب
- الانضمام كوكيل `/agents` — نموذج التقديم + شرح المزايا
- تسجيل الدخول `/login` — للوكلاء والمشرفين

### 4.2 لوحة تحكم المشرف (Admin Dashboard)

#### الرئيسية `/admin`
- إجمالي الحجوزات (حديثة + مؤكدة)
- إجمالي المدفوعات المسجّلة (بالريال)
- البرامج المنشورة
- الوكلاء المعتمدون + المعلّقون
- تنبيهات: طلبات التقديم الجديدة + التحويلات المعلّقة
- جدول أحدث الحجوزات

#### إدارة الحجوزات `/admin/bookings`
- قائمة كاملة مع فلتر الحالة والبحث
- صفحة تفاصيل شاملة:
  - بيانات العميل وتعديلها
  - ربط البرنامج بالحجز
  - تحريك الحالة (جميع الانتقالات المسموح بها)
  - إدخال السعر الإجمالي
  - تسجيل المدفوعات (النقد، التحويل، البطاقة)
  - إدارة التحويلات وتعيين السائقين
  - تعيين الوكيل والمدير
  - المحادثة مع العميل
  - إدارة نقاط التقدم (Milestones)
  - ملاحظات داخلية وملاحظات للعميل

#### إدارة البرامج `/admin/programs`
- قائمة كاملة مع فلترة بالنوع والحالة
- إنشاء وتعديل البرامج (سياحية ودراسية)
- الموافقة على برامج الوكلاء
- إنشاء الجدول اليومي: أيام وعناصر (أنشطة، فنادق، وجبات، تنقلات، رحلات جوية)

#### إدارة الوجهات `/admin/destinations`
- إنشاء وتعديل الوجهات
- بناء شجرة المناطق الجغرافية (منطقة → محافظة → مدينة → حي)
- إدارة المعالم والأماكن السياحية لكل منطقة

#### إدارة الوكلاء `/admin/agents`
- قائمة شاملة بجميع الوكلاء وأرصدتهم
- تعديل معدلات العمولة لكل وكيل
- منح / سحب صلاحية برامج الدراسة
- تعليق / تفعيل الحسابات
- عرض كشف حساب الوكيل

#### طلبات التقديم `/admin/applications`
- مراجعة طلبات الانضمام كوكيل
- الموافقة (تُنشئ مستخدم + ملف وكيل تلقائياً) أو الرفض

#### السائقون والمزوّدون
- `/admin/drivers` — إدارة السائقين (المركبة، الطاقة، منطقة الخدمة)
- `/admin/providers` — إدارة مزودي الخدمات (نقل، فنادق، أخرى)
- `/admin/transfers` — نظرة شاملة على جميع التحويلات

#### إدارة المستخدمين والإعدادات
- `/admin/users` — حسابات الموظفين (مشرف / وكيل)
- `/admin/messages` — صندوق الرسائل الواردة من نموذج التواصل
- `/admin/settings` — إعدادات CMS (Hero، بيانات التواصل)

## 5. منطق الأعمال الجوهري

### 5.1 دورة حياة الحجز

```
           [WEBSITE / AGENT / ADMIN]
                     ↓
               NEW (جديد)
                     ↓
           CONTACTED (تم التواصل)
                     ↓
            QUOTED (تم التسعير)          ← يظهر السعر للعميل هنا
                     ↓
          CONFIRMED (مؤكد) *             ← تُنشأ قيود السجل المالي هنا
                     ↓
          COMPLETED (مكتمل) *

* حصري للمشرف — الوكيل لا يصل إليهما
↓ CANCELLED ممكن في أي مرحلة (بواسطة المشرف)
```

### 5.2 أنواع البرامج

| النوع | الفئة | الحقول المميزة | المدة |
|-------|-------|---------------|-------|
| رحلة داخلية | TOUR / DOMESTIC | سعر/شخص، جدول يومي، يشمل/لا يشمل | بالأيام |
| رحلة دولية | TOUR / INTERNATIONAL | نفس الداخلية + وجهة دولية | بالأيام |
| دراسة لغة | STUDY / LANGUAGE | المعهد، الرسوم الدراسية (min/max) | بالأسابيع |
| قبول جامعي | STUDY / UNIVERSITY | الجامعة، المتطلبات، الخدمات المشمولة | بالأسابيع |
| ابتعاث | STUDY / SCHOLARSHIP | المنح، 7 مراحل افتراضية | بالأسابيع |

### 5.3 نظام الوجهات الجغرافية

```
Destination (وجهة)
   └── Area: REGION (منطقة)
         └── Area: PROVINCE (محافظة)
               └── Area: GOVERNORATE (قضاء)
                     └── Area: CITY (مدينة)
                           └── Area: DISTRICT (حي)
                                 └── Attraction (معلم سياحي)
```
تورث منطقة الخدمة: سائق مرتبط بـ REGION يغطّي كل CITYs التابعة لها.

### 5.4 نظام العمولات والسجل المالي

#### عند تأكيد الحجز (CONFIRMED) تُنشأ تلقائياً:

| نوع القيد | الحساب | المثال (حجز 5,000 ر.س) |
|-----------|--------|----------------------|
| COMMISSION | `+totalPrice × commissionRate%` | +500 ر.س (10%) |
| PLATFORM_FEE | `−totalPrice × platformFeeRate%` | −250 ر.س (5%) |
| **صافي الوكيل** | | **+250 ر.س** |

#### للوكيل المدير (Delegated Manager):
- COMMISSION فقط: `+totalPrice × manageCommissionRate%` (افتراضي 5%)
- بدون PLATFORM_FEE

#### أنواع قيود السجل:

| النوع | الاتجاه | من يُنشئه |
|-------|---------|-----------|
| COMMISSION | + (لصالح الوكيل) | تلقائي عند CONFIRMED |
| PLATFORM_FEE | − (خصم على الوكيل) | تلقائي عند CONFIRMED |
| PAYOUT | − (صرف للوكيل) | المشرف يدوياً |
| ADJUSTMENT | ± (تصحيح) | المشرف يدوياً |

**رصيد الوكيل** = مجموع جميع القيود (موجبة وسالبة)

### 5.5 نظام الإحالة

- كل وكيل يملك `referralCode` فريد (مثال: `KH1A2B3`)
- رابط الإحالة: `{domain}/programs?ref={referralCode}`
- عند الحجز عبر الرابط: تُنسب الحجز للوكيل تلقائياً
- رموز غير صالحة تُتجاهل بصمت

### 5.6 نظام المراحل (Milestones) — خاص بالدراسة

عند تأكيد حجز برنامج دراسي، تُنشأ تلقائياً 7 مراحل:

| # | المرحلة |
|---|---------|
| 1 | تجهيز الملف والمستندات |
| 2 | تقديم طلب القبول |
| 3 | استلام خطاب القبول |
| 4 | إجراءات التأشيرة الدراسية |
| 5 | تأمين السكن |
| 6 | حجز الطيران والاستقبال |
| 7 | الوصول وبدء الدراسة |

الحالات: `PENDING → IN_PROGRESS → DONE`

### 5.7 دورة حياة الوكيل

```
التقديم العام (/agents)
      ↓
AgentApplication: NEW
      ↓ [مراجعة المشرف]
APPROVED → ينشئ: User + AgentProfile (status: PENDING)
      ↓ [موافقة المشرف]
AgentProfile: APPROVED ← يستطيع إنشاء برامج وقبول حجوزات
      ↓ [قرار المشرف]
AgentProfile: SUSPENDED ← يرى الحجوزات القديمة فقط
```

### 5.8 دورة حياة البرنامج

| الحالة | المعنى | مَن يعدّلها |
|--------|--------|-------------|
| DRAFT | مسودة غير منشورة | الوكيل / المشرف |
| PUBLISHED | منشور | الوكيل / المشرف |
| ARCHIVED | مؤرشف | المشرف |

**الرؤية (Visibility):**

| القيمة | السلوك |
|--------|--------|
| PUBLIC | يظهر في التصفح العام |
| UNLISTED | يُصل إليه برابط مباشر فقط |
| PRIVATE | مخفي تماماً |

برامج الوكلاء تتطلب `isApproved = true` من المشرف قبل الظهور.

## 6. البنية التقنية

### المكدّس التقني (Tech Stack)

| الطبقة | التقنية |
|--------|--------|
| Frontend | Next.js 16 (App Router) + React |
| Styling | Tailwind CSS v4 + shadcn/ui |
| Database | PostgreSQL + Prisma 6 ORM |
| Hosting | Cloudflare Workers + @opennextjs/cloudflare |
| DB Proxy | Cloudflare Hyperdrive |
| Auth | Session-based (SHA256 token, HTTP-only cookie) |
| Passwords | WebCrypto PBKDF2 (بدون bcrypt) |
| Language | TypeScript |
| Font | Cairo Variable (عربي) |
| Direction | RTL (dir=rtl على HTML) |

### نماذج البيانات الرئيسية

```
User ──────────── AgentProfile
                       │
                  ┌────┤────────────┐
                  │    │            │
              Programs  BookingRequest  LedgerEntry
                  │         │
           ItineraryDay   Payment
                  │       Transfer
           ItineraryItem  BookingMessage
                         BookingMilestone

Destination ── Area ── Attraction
                └── Driver
                └── ServiceProvider
```

## 7. المتطلبات غير الوظيفية

| المتطلب | التفاصيل |
|---------|---------|
| **الأداء** | Cold start < 200ms على Cloudflare Workers |

| **SEO** | Metadata ديناميكية لكل صفحة برنامج ووجهة |

## ملاحق

### أ. قاموس المصطلحات

| المصطلح | الشرح |
|---------|-------|
| **Booking Code** | رمز الحجز الفريد (مثال: KH-7F3K2A) |
| **Referral Code** | كود الوكيل للإحالة (مثال: KH1A2B3) |
| **Ledger** | سجل المعاملات المالية للوكيل |
| **Transfer** | طلب تنقل (سيارة، حافلة) ضمن الحجز |
| **Milestone** | مرحلة من مراحل معالجة ملف الدراسة |
| **isApproved** | علم الموافقة الإدارية على البرنامج |
| **managerAgentId** | الوكيل المفوَّض لإدارة الحجز (مختلف عن وكيل الإحالة) |
| **UNLISTED** | برنامج غير مدرج في البحث لكن قابل للوصول برابط |

### ب. حالات الحجز

| الحالة | المعنى | مَن يحرّكها |
|--------|--------|-------------|
| NEW | حجز جديد لم يُتواصل معه | — |
| CONTACTED | تم التواصل مع العميل | وكيل / مشرف |
| QUOTED | تم تقديم عرض سعر | وكيل / مشرف |
| CONFIRMED | مؤكد رسمياً، تُنشأ العمولات | مشرف فقط |
| COMPLETED | تم تنفيذ الرحلة بنجاح | مشرف فقط |
| CANCELLED | ملغي | مشرف فقط |
