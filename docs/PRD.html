الرؤية والهدف

الرؤية

منصة رقمية سعودية متكاملة تُمكّن المسافر العربي من اكتشاف البرامج السياحية والدراسية بالخارج — من التصفح والاختيار حتى المتابعة اليومية — في مكانٍ واحد وبشفافية تامة.

الهدف

بناء منظومة تجمع بين العملاء الباحثين عن تجارب سفر منظّمة، والوكلاء الراغبين في تسويق برامجهم، وإدارة المنصة التي تُشرف على العمليات وتضمن الجودة — مع نظام مالي واضح لتوزيع العمولات وتتبّع المدفوعات.

الوضع الحالي: المنتج في مرحلة MVP مكتمل ومنشور بالكامل، يشمل جميع الميزات الموثّقة في هذه الوثيقة.

المشكلة والفرصة

المشكلة

الجهةالمشكلة

الوكيلأدوات إدارة البرامج والمتابعة المالية مبعثرة أو غير موجودة بالعربية
مزوّد الخدمةصعوبة بناء قاعدة عملاء وتتبّع العمولات بدون نظام احترافي

الفرصة

  • سوق السياحة الداخلية السعودية في نمو متسارع (رؤية 2030)
  • الطلب المتزايد على برامج الدراسة بالخارج من الشباب السعودي
  • غياب منصة عربية أولى (RTL-native) تجمع السياحة والدراسة معاً
  • نموذج عمل قابل للتوسع عبر شبكة الوكلاء

ميزات المنتج الحالية

4.1 الواجهة العامة (Public)

الصفحة الرئيسية /

  • Hero section قابل للتخصيص من لوحة التحكم
  • بحث سريع بالنوع (سياحة / دراسة) والوجهة
  • إحصائيات المنصة (الوجهات، البرامج، المدن، الدعم 24/7)
  • بطاقات الفئات الأربع: رحلات داخلية، دولية، دراسة لغة، جامعات وابتعاث
  • البرامج المميزة + الوجهات المختارة
  • قسم "كيف يعمل خطار؟" (3 خطوات)
  • آراء العملاء (Testimonials)
  • قسم الانضمام كوكيل

البرامج السياحية /programs

  • chip filters أفقية: كل الأنواع / داخلي / دولي
  • فلترة إضافية بالوجهة + عداد النتائج + مسح الفلاتر
  • بطاقة البرنامج: صورة، اسم، ملخص، سعر، المدة، الوجهة

تفاصيل البرنامج /programs/[slug]

  • صورة غلاف بارزة مع breadcrumb
  • الجدول اليومي التفصيلي: أنشطة، تنقلات، فنادق، وجبات، رحلات جوية بأوقاتها
  • قائمة "يشمل" و"لا يشمل"
  • نموذج طلب الحجز + تواصل واتساب
  • Sticky inner nav للتنقل بين أقسام الصفحة

برامج الدراسة /study و /study/[slug]

  • chip filters: كل الأنواع / دراسة لغة / جامعي / ابتعاث
  • Hero banner مخصص بـ gradient
  • اسم المعهد، المدينة، المدة، نطاق الرسوم، المتطلبات

الوجهات /destinations و /destinations/[slug]

  • بطاقات overlay غامرة بلا حدود
  • Hero بارتفاع 60% من الشاشة مع صورة كاملة
  • شجرة المناطق الجغرافية + المعالم السياحية المصنّفة
  • البرامج المتاحة في هذه الوجهة

متابعة الحجز /b/[code]

  • صفحة عامة لا تتطلب تسجيل دخول
  • حالة الحجز + تفاصيل الرحلة
  • الجدول اليومي من البرنامج المرتبط
  • مؤشر التقدم (Milestones) خاصة لبرامج الدراسة
  • الدفعات: الإجمالي، المدفوع، المتبقي
  • التحويلات المجدولة مع بيانات السائق
  • المحادثة مع فريق الدعم

منطق الأعمال الجوهري

5.1 دورة حياة الحجز

NEW ← CONTACTED ← QUOTED ← CONFIRMED * ← COMPLETED *

* حصري للمشرف — الوكيل لا يصل إليهما  |  CANCELLED ممكن في أي مرحلة بواسطة المشرف

السعر يظهر للعميل عند QUOTED  |  قيود العمولة تُنشأ عند CONFIRMED

5.2 أنواع البرامج

النوعالفئةالحقول المميزةالمدة
رحلة داخليةTOUR / DOMESTICسعر/شخص، جدول يومي، يشمل/لا يشملبالأيام
رحلة دوليةTOUR / INTERNATIONALنفس الداخلية + وجهة دوليةبالأيام
دراسة لغةSTUDY / LANGUAGEالمعهد، الرسوم (min/max)بالأسابيع
قبول جامعيSTUDY / UNIVERSITYالجامعة، المتطلبات، الخدماتبالأسابيع
ابتعاثSTUDY / SCHOLARSHIPالمنح، 7 مراحل افتراضيةبالأسابيع

5.3 نظام العمولات والسجل المالي

عند تأكيد الحجز (CONFIRMED) تُنشأ تلقائياً قيدا السجل المالي للوكيل.
نوع القيدالحسابمثال (حجز 5,000 ر.س)
COMMISSION+ totalPrice × commissionRate%+500 ر.س (10%)
PLATFORM_FEE− totalPrice × platformFeeRate%−250 ر.س (5%)
صافي الوكيل+250 ر.س
نوع القيدالاتجاهمن يُنشئه
COMMISSION+ لصالح الوكيلتلقائي عند CONFIRMED
PLATFORM_FEE− خصم على الوكيلتلقائي عند CONFIRMED
PAYOUT− صرف للوكيلالمشرف يدوياً
ADJUSTMENT± تصحيحالمشرف يدوياً

5.4 المراحل (Milestones) — خاص ببرامج الدراسة

عند تأكيد حجز برنامج دراسي، تُنشأ تلقائياً 7 مراحل:

  1. تجهيز الملف والمستندات
  2. تقديم طلب القبول
  3. استلام خطاب القبول
  4. إجراءات التأشيرة الدراسية
  5. تأمين السكن
  6. حجز الطيران والاستقبال
  7. الوصول وبدء الدراسة

الحالات: PENDING → IN_PROGRESS → DONE

5.5 نظام الإحالة

  • كل وكيل يملك referralCode فريد (مثال: KH1A2B3)
  • رابط الإحالة: {domain}/programs?ref={referralCode}
  • عند الحجز عبر الرابط: تُنسب الحجز للوكيل تلقائياً
  • رموز غير صالحة تُتجاهل بصمت

5.6 دورة حياة الوكيل

تقديم عام ← مراجعة المشرف ← PENDING ← APPROVED (أو SUSPENDED)

5.7 دورة حياة البرنامج

الحالةالمعنىالرؤية (Visibility)
DRAFTمسودة غير منشورةلا يظهر
PUBLISHEDمنشورPUBLIC / UNLISTED / PRIVATE
ARCHIVEDمؤرشفلا يظهر

برامج الوكلاء تتطلب isApproved = true من المشرف قبل الظهور للعملاء.
