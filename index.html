دورة عمل متكاملة

من طلب العميل حتى عمولة الوكيل — مع حماية مالية مدمجة

  1. العميل يتصفح برنامجاً عبر رابط الوكيل ?ref=AHMED10 ويرسل طلب حجز — يُنسب للوكيل تلقائياً ويصله رقم طلب ورابط متابعة.
  2. الوكيل/الإدارة يتابعون الطلب: تواصل ثم تسعير (الوكيل يقف هنا — التأكيد صلاحية إدارية).
  3. عند التأكيد (يشترط تحديد السعر) تُنشأ آلياً قيود عمولة الوكيل + ورسوم المنصة − حسب نسبه، مرة واحدة فقط مهما تكررت المحاولة.
  4. تُضاف الدفعات وطلبات النقل وتُسند للسائقين — وكل ذلك يظهر للعميل في صفحة رحلته لحظياً.
  5. الوكيل يرى أثر كل ذلك في كشف حسابه، والإدارة تسجل دفعاته وتسوياته.

جرّبها بنفسك في ٣ خطوات

تحتاج Node 20+ و pnpm و PostgreSQL (أو SQLite كبديل موثق في README)

# 1) clone + database
git clone https://github.com/mhwar/khuttar && cd khuttar
createdb khuttar  # أو اتبع README لإنشاء المستخدم

# 2) setup
cp .env.example .env
pnpm install
pnpm prisma migrate dev
pnpm db:seed   # بيانات تجريبية كاملة + حسابات الدخول

# 3) run
pnpm dev       # → http://localhost:3000
